# ISS Screensaver

Live video of Earth from the International Space Station, with a map of where it is right now.

Live at https://www.richardwestenra.com/iss/

## Running locally

No build step. Serve the repo root with any static server:

```sh
npx serve
```

## Deploying

GitHub Pages serves the `master` branch root directly. Push to `master` and it's live.
